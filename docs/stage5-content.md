## 一、殘局訓練（4 個課題，共 28 個局面）

**驗證方法**

- 殺王課題（后、車、雙車）：局面由固定種子隨機產生（白先走），條件：局面合法、黑王沒有被將軍、黑方有棋可走（沒有一開始就逼和）、沒有白子一開始就可以被黑王白吃。再去 Lichess 殘局庫（tablebase.lichess.ovh）查「將死步數 N」，每個目標步數挑候選；然後用 **Stockfish 19（depth 30，或者每個局面 5 秒，先到先停）** 要算出同一個 mate N；再做一次「自我對弈」：白方用提示設定（depth 14）、黑方用防守設定（depth 14，Stockfish 全力，沒有降低強度），必須在步數上限內將死。三項都合格才收。
- 王兵對王：局面人手設計，每個局面標明預期結果（win／draw），要同 **Lichess 殘局庫** 同 **Stockfish（depth 30 或 5 秒）** 兩邊一致才收：贏＝殘局庫 win 而且 Stockfish 分數 ≥ 300 cp（或將死分數）；和棋＝殘局庫 draw 而且 Stockfish 分數絕對值 ≤ 50 cp。「贏」課題再做自我對弈：兵要升變，而且升變後 Stockfish 仍然判斷白方贏（后沒有被吃）。
- **殘局庫查證結果**：全部局面都已經用 Lichess 殘局庫（tablebase.lichess.ovh/standard）查過，網絡可以連接，所以不是只靠 Stockfish。查到嘅 category／dtm／dtz 記錄喺下表同 `docs/stage5-endgames-tb.json`。
- 步數上限＝引擎最短將死步數 × 2 + 5（最多 50 步）。王兵對王「贏」課題冇「最短將死」，所以 shortest ＝ 引擎自我對弈升變嘅白方步數（不是嚴格最短），上限用同一條公式。
- 星星：3 星＝不用提示而且步數 ≤ 最短 + 3；2 星＝不用提示、上限內完成；1 星＝用過提示完成；判斷題答對 3 星、答錯 0 星。提示每次練習最多 3 次。

### 后殺王（王＋后 對 王，id：`kqk`）

**說明卡（App 顯示，書面語）**

1. 先用后把對方的王「圈」在越來越小的範圍內：后和對方的王保持一個馬步的距離，像用盒子把王框住。
2. 每一步都要讓盒子縮小一點，但一定要讓對方的王有格可走，否則會逼和（對方沒有棋可走又沒有被將軍，就是和棋）。
3. 對方的王被逼到棋盤邊線之後，把自己的王走近，與后配合。
4. 最後用后在對方的王旁邊將軍，並且由自己的王保護后，就是將死。
5. 每走一步先問自己：走完之後，對方的王還有格可以走嗎？后會不會被對方的王吃掉？

### 車殺王（王＋車 對 王，id：`krk`）

**說明卡（App 顯示，書面語）**

1. 王和車合作：車像一道牆，把對方的王限制在棋盤的一邊；自己的王負責向前推進。
2. 把車放在較遠的一行，讓對方的王不能越過，再用自己的王一步一步靠近對方的王。
3. 兩個王面對面（中間隔一格，叫做「對王」）而輪到對方走棋時，對方的王只能後退或讓開；這時用車將軍，把王逼退一行。
4. 重複這個過程，把對方的王一行一行逼到邊線；最後用車在邊線將軍，並由自己的王擋住對方的王的退路，就是將死。
5. 小心：車旁邊有對方的王而沒有保護時會被吃掉；也要小心逼和。

### 雙車梯形殺（王＋兩枚車 對 王，id：`k2rk`）

**說明卡（App 顯示，書面語）**

1. 兩枚車輪流將軍，像爬梯子一樣：一枚車將軍，把對方的王逼到下一行。
2. 另一枚車馬上走到更靠前的一行將軍，兩枚車要放在不同的行，不要互相擋住。
3. 每次將軍都把對方的王逼向邊線一行，重複幾次就會到達邊線。
4. 到了邊線，其中一枚車將軍，另一枚車封住王能逃去的行，就是將死。
5. 這個殺法不需要用自己的王，但要小心車不要被對方的王吃掉。

### 王兵對王（對王、正方形法則，id：`kpk`）

**說明卡（App 顯示，書面語）**

1. 對王（Opposition）：兩個王中間隔一格面對面時，輪到走棋的一方要讓開，所以要想辦法讓對方輪到走棋。
2. 王要走在兵的前面，才能護送兵升變；王走到兵前面的「關鍵格」（兵前面第二格附近），通常就能贏。
3. 正方形法則：從兵畫一個正方形到底線，如果對方的王沒有辦法進入這個正方形，兵就可以直接跑去升變。
4. 邊兵（a 兵或 h 兵）很特別：對方的王走進角落就是和棋，白方不能贏。
5. 判斷局面時先看：王在兵的前面還是後面？誰拿到對王？是不是邊兵？
