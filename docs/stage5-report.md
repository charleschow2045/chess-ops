- 殺王局面：固定種子隨機產生 → Lichess 殘局庫（tablebase.lichess.ovh）查將死步數 N → Stockfish 19（depth 30，或 5 秒）要算出同一個 mate N → 自我對弈（白方用提示設定、黑方用防守設定，同 App 一樣）要喺上限內將死。三項都過先收。
