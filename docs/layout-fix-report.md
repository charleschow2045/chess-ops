# 修正：棋盤上下跳動

iPad 實測：對電腦下棋每走一步，棋盤上下跳兩次。

## 原因
1. **對電腦下棋**：「先想三問」提醒只喺輪到玩家時顯示（`hidden` 收起）。電腦思考時收起 → 棋盤向上移 66px；輪返玩家時再出現 → 向下移。對局結束時提醒亦被收起，再移一次。
2. **引擎載入提示**（對電腦下棋、殘局訓練）：「引擎載入中…」卡片放喺 `#stage` 上面，載入完成後消失 → 棋盤向上移約 103px（首次開局時發生）。
3. **走棋前三問、規則快測**：棋盤上方嘅題目文字每條長短唔同（1–2 行），換題時棋盤移 29px。

## 修正
- 提醒行：永遠佔位、固定高度 58px；電腦思考／對局結束時只係變淡（`opacity .4`），唔收起；玩家撳「收起」後同樣高度（文字變「三問提醒」＋「展開」）；設定關閉就由開局起完全唔出現。
- 狀態行（所有頁面共用 `.status-line`）：固定高度 28px、單行、太長用省略號。
- 被吃棋子列／玩家列：固定高度、唔換行。
- 引擎載入／出錯提示：由棋盤上面搬到頁面最下面（棋盤同按鈕下面），出現或消失都唔會推動棋盤，亦唔會遮住按鈕。
- 三問、規則快測：用 `CO.Util.fixTextHeight` 量度所有可能嘅題目文字，取最高者做固定高度（視窗大細改變時重新量度）。
- 其他頁面（謎題、開局、殘局判斷、四個小遊戲、我的對局分析、我的謎題、賽後檢討）量度後本來就冇跳動，唔需要改。

## 量度（`tools/layout-check.js`）
每個有棋盤嘅頁面喺各種狀態（輪到玩家、電腦思考中、被將軍、提示箭頭、答對／答錯回饋、提醒收起／展開、對局結束、引擎載入中、換題…）量度 `cg-board` 嘅文件座標 top（`getBoundingClientRect().top + scrollY`），並用 `requestAnimationFrame` 連續取樣抓「中途跳一下」。820×1180 同 1180×820 都跑，容許差距 ≤ 1px。對電腦下棋真走 3 個來回（6 步）。

| 場景（820×1180；1180×820 結果相同） | 修正前差距 | 修正後差距 |
|---|---|---|
| 對電腦下棋（執白，3 個來回） | 168.8px | 0px |
| 對電腦下棋（執黑，3 個來回） | 102.8px | 0px |
| 對電腦下棋：被將軍（提醒關閉／開啟） | 102.8／168.8px | 0px |
| 殘局練習（引擎載入、提示、黑方思考、結束） | 102.8px | 0px |
| 走棋前三問（Q1–Q3、下一個局面） | 29px | 0px |
| 規則快測：吃過路兵、和棋兩組 | 29px | 0px |
| 戰術謎題、開局路線／小測、殘局判斷、一步將死、找出將軍、騎士迷宮、兵仗、規則快測其餘 4 組、我的對局分析、我的謎題、賽後檢討 | 0px | 0px |

原始數字：`docs/layout-check-before.json`（修正前，用 main 舊版跑）、`docs/layout-check.json`（修正後）。
